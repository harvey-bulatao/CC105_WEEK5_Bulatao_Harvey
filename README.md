Refactored Linear Data Architecture Subsystem

Project Description

This project is a refactored version of a legacy linear data subsystem for NTC\_CC105 Data Structure with Lab.

The system demonstrates basic linear data structure operations such as:

\- Adding items  
\- Removing items  
\- Searching items  
\- Displaying items  
\- Dynamic array resizing  
\- Matrix transposition

Main Improvements

The original code was improved by:

\- Removing global variables  
\- Using a "DynamicArray" class  
\- Fixing memory leaks using "delete\[\]"  
\- Adding index validation  
\- Removing unnecessary nested loops  
\- Improving naming consistency  
\- Using safer array traversal

Technologies Used

\- C++  
\- C++17  
\- Dynamic Arrays  
\- Classes and Objects  
\- Linear Search  
\- Basic Matrix Operations

Files

\- "RefactoredLinearSubsystem.cpp" – Main refactored C++ program  
\- "Test cases.md" – Unit testing results  
\- "ComplexityAnalysis.md" – Big-O complexity analysis

How to Run

1\. Open "RefactoredLinearSubsystem.cpp".  
2\. Compile using a C++17 or higher compiler.  
3\. Run the program.  
4\. Check the output for insertion, searching, deletion, and matrix transpose.

Expected Output

The program should display:

\- Added items  
\- Current list contents  
\- Search result  
\- Removal results  
\- Invalid index messages  
\- Transposed 3×3 matrix  
\- Program completion message
